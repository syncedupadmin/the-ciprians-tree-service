# The Ciprians Tree Service demo

Source-grounded demonstration site for The Ciprians Tree Service at 904 Bland Ave, Shelbyville, Kentucky.

## Sources and assets

- Verified services, experience, email, phone and Instagram: `https://theciprianservices.com/` and its service page.
- Exact current business logo: downloaded unchanged from the current business site CDN (`whatsapp-image-2025-04-16...jpeg`).
- Photography: real Unsplash photography already selected by the current business site. No generated imagery is used.

## Demo policy

The site sends `X-Robots-Tag: noindex, nofollow, noarchive` and returns a disallow-all `robots.txt` until a real production-domain launch is approved.
